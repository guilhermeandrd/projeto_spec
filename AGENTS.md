# Instruções para o Projeto

## Sobre o projeto

Dashboard de gerenciamento de tarefas para estudos de alunos do ensino superior. 

# Regras não-negociáveis
- Painel responsivo usando uma abordagem *MOBILE FISRT*
- Banco de utilizado será o SQLite. 
- Credenciais de banco, chaves e tokens *NUNCA* deverão ficar no código, use arquivos `.env`. 
- Use HTML, CSS, JAVASCRIPT e Express.js. 


# Como trabalhar neste repositório

1. Antes de implementar, leia a spec em `specs/<funcionalidade>` (requirements.md, design.md, tasks.md).

2. Não implemente nada fora da spec. Se algo estiver ambiguo, pare e pergunte. 

3. Siga a ordem numérica das pastas em `specs/` (acessos a dados é a fundação das demais).

4. Código fonte em `src/`, Testes em `tests/`. Crie `requirements.txt` com as dependências usadas. 

5. Use a interface disponibilizada em `docs/interface/interface.png` como base para as telas. 

6. Use a interface disponibilizada em `docs/interface/interface.png` para tipografias e cores deste projeto.
